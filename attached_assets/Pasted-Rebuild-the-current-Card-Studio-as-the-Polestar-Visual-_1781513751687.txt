Rebuild the current Card Studio as the Polestar Visual Brief Builder.

The current version is too form heavy. It feels like a data entry screen, not a visual briefing product. The new version needs to work more like Canva for intelligence products, but locked to Polestar branding.

The purpose of this tool is to let me create polished visual intelligence briefs that combine maps, icons, charts, timelines, text panels, summary boxes, risk ratings and recommendations in one finished branded output.

The visual brief must be the main workspace. The user should build and edit directly on the canvas, not through a long static form.

TEMPLATES AND LAYOUTS

Templates must be visual layouts, not report categories.

Do not build the template system around subjects like Country Risk, Protest Update, Maritime Disruption or Spot Report. Those are topics. The tool must be more flexible than that.

The user should choose the shape of the output, then use it for any topic.

Create the following starting layouts:

Map led brief

A large map with supporting text panels, key points, risk rating and outlook.

Route and movement brief

A map with route line, direction arrows, start and end points, legend, timing and movement assessment.

Event awareness brief

Headline, date, key locations, likely timeline, watch areas, advice and executive summary.

Timeline led brief

Horizontal or vertical timeline with supporting risk and impact panels.

Operations advisory brief

Advice focused layout with icons, actions, warnings, affected areas and recommended posture.

Executive visual summary

Clean senior leadership layout with key judgement, impact, outlook, rating and next steps.

Multi panel infographic

Dense layout combining map, icons, text boxes, timeline, watch areas, advice and summary table.

Social media visual

Simplified external facing layout for LinkedIn or X.

The same layout should be usable for any topic, including protests, port disruption, strikes, border closures, weather events, kidnapping trends, supply chain issues, travel disruption, facility security issues, political risk updates and operational disruption.

WHAT THIS MUST NOT BE

Do not create another long form based card editor.

PRODUCT AIM

The finished product should let the user quickly create high polish Polestar visual intelligence products containing maps, icons, graphs, timelines and text.

The user chooses a visual layout, drops in content, adjusts the canvas and exports a finished professional brief.
