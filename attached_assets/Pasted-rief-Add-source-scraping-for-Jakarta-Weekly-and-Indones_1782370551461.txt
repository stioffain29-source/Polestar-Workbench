rief: Add source scraping for Jakarta Weekly and Indonesia Weekly reports

We have added two new weekly reports:

Jakarta Weekly
Indonesia Weekly

The task is to enhance the existing source scraping and incident collection so these reports are populated with relevant local news, official updates and public social/community signals.

This is an enhancement to the existing reporting system, not a rebuild.

Objective

Add reliable source coverage for Jakarta and wider Indonesia so the weekly reports can identify and summarise:

protests and demonstrations
civil unrest
crime and security incidents
floods, fires, earthquakes and other disruption
transport disruption
police activity
government restrictions or official warnings
airport, port, road and city disruption
operational issues relevant to business travellers, facilities and supply chain

Confidence rules

Use a simple confidence model:

High confidence

Official source, police source, emergency management source, or multiple credible media sources confirming the same incident.

Medium confidence

Single credible news source, or a local source with clear location and incident details.

Low confidence

Public social media or community report with no independent confirmation.

Low confidence items can be collected, but should not automatically appear as confirmed report content unless verified.

Deduplication

Deduplicate by:

same incident location
same date
similar title
similar body text
same source URL
same event described by multiple sources

Where multiple sources report the same incident, retain the best source as the primary item and attach the others as supporting sources.
