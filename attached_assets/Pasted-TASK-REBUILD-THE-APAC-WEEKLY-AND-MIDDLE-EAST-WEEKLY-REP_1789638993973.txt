==================================================

THIS IS CRITICAL.

Multiple articles describing the same event must be combined into ONE development.

Do not publish individual media stories as separate developments.

Example:

Five articles reporting an Indian fuel export duty change = ONE regulatory/energy development.

Six articles reporting one Saudi pipeline attack = ONE development.

Several stories about the same protest = ONE development unless there are genuinely separate events.

Cluster source material by:

Country
Location
Event
Date
Actors
Underlying incident
Policy decision
Operational consequence

Use multiple sources to improve confidence and detail.

Do not use multiple sources to create multiple report entries.
