---
name: Report disclaimer typography
description: Workbench-wide disclaimer size requirement.
---

All report disclaimer body text must use 9-point Roboto, including previews, PDFs, and Word exports.

**Why:** the owner explicitly required one disclaimer size across every report in the Workbench, rather than topic-specific sizes.

**How to apply:** use CSS `9pt` (12px), PDF font size 9, and DOCX half-point size 18. Keep measurement and rendering metrics aligned. Do not resize ordinary report prose or add backgrounds; Energy specifically has no disclaimer panel.
