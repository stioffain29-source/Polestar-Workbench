Shipping monitor and report must use the same validated development set for the same window. Different publication dates, publishers, headline wording, and congestion-versus-rerouting emphasis do not constitute new developments. A material operational change may remain separate.

**Why:** On 2026-09-10 the owner explicitly replaced the former asymmetric monitor/report dedup policy with one canonical maritime dataset. The old permission for monitor undercounting and raw report totals is no longer valid.

**How to apply:** Resolve underlying developments from relational event evidence, not merely a provider's independently invented text key. Keep physical event geography distinct from indirect route consequences; keep commercial attack, seizure, piracy and naval activity distinct. Compare monitor/report outputs using identical reporting windows.
