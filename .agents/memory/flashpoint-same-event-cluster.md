---
name: Flashpoint same-event syndication clustering
description: dedupeByTitle's fuzzy third pass that collapses one event's varying-casualty / place-framing copies, and the country-name over-merge trap
---

- `dedupeByTitle` (flashpointReportDataset.ts) has THREE passes: exact `titleKey`, `topicSignature` parity-bucket, then a fuzzy same-event `clusterSameEvent` union-find. The first two CANNOT bridge syndicated rewrites that vary the casualty number or the place framing (e.g. one prison riot reported as ~8 rows: "Sri Lanka prison riot" vs "Negombo prison riot", "kills 19" vs "toll rises to 25"). The third pass exists for exactly that.
- Link rule: two rows link when (same country or one unknown) AND within 3 days AND share >= 2 anchor tokens AND do NOT name mutually-exclusive subjects. `anchorTokens` drops numbers + generic mobilisation/casualty/reporting words (`SAME_EVENT_NON_ANCHOR`). `subjectTokens` = anchors minus concrete recurring event nouns (`SAME_EVENT_TYPE_NOUN`: riot/prison/fire/blast...). `distinctSubjects` blocks the edge only when BOTH sides carry an exclusive subject (different city/actor) — a subset/superset pairing links (a bridging headline naming both framings closes the cluster).

**Why:** `dedupeByTitle` is EXPORTED and drives BOTH the flashpoint report Related-Incidents tables (via `enriched`) AND the flashpoint MONITOR/dashboard card (via `trueIncidents.resolveFlashpointTrue`). Adding the third pass adds merging to the monitor too — that is intended (monitor counts distinct events). The winner is `sevDateBetter` (highest severity, then newest), so dedup only DROPS rows, never fabricates — the Extreme survivor is preserved, not averaged.

**How to apply:** the sharp edge is multi-word COUNTRY names. "Sri Lanka" tokenises to {sri, lanka}, which alone hits the >= 2 shared-anchor threshold and (being a subject-subset) never trips `distinctSubjects`, so two DIFFERENT same-country events would merge. `countryNameTokens` excludes each row's country-name tokens from the shared-anchor count, forcing >= 2 real place/event anchors BEYOND the nationality. If you tune thresholds, keep country tokens out of the count and re-run the regression tests in `__tests__/workbench/flashpointTitleClean.test.ts` (8→1 Sri Lanka collapse; cross-city and country-only-shared stay-2 guards). The separate generic `monitorDedupe.ts` stays conservative (full-title only, no fuzzy) — do not merge these two.
