---
name: Report footer standard
description: Fixed placement rule for page numbering across every report format.
---

**Rule:** Every report displays page numbering in the footer. Do not move it to the top, suppress it for one report type, or add a second page number in the body-page header.

**Why:** The owner confirmed that footer numbering is a long-standing standard shared across all reports.

**How to apply:** Preserve the shared footer when changing PDF chrome or topic-specific exports. Treat any number appearing at the top as a separate rendering defect, not a reason to remove footer numbering.
